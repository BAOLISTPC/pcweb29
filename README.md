- 网站名、页脚与左上角品牌统一为「PC的网站」。
- 使用 `assets/avatar.png` 作为头像。
- 首页主轴改为「生活 · 足球 · 工作」。
- 新增生活板块，用于后续上传旅行、游玩和日常照片。
- 足球新增「看球」板块，用于后续上传现场观赛照片和视频。

- 2026-07-22 石鼓八人比赛视频继续精确绑定到对应二级比赛页。
