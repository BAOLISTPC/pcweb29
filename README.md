- 新增 2026-08-12、2026-08-18 两条八人制比赛视频；比赛二级页会按日期自动匹配。

## GitHub Pages 更新

把本目录内容整体上传并覆盖原仓库文件即可，尤其不要漏掉：

- `reports/`：五份年度球探报告 PDF
- `games.html` / `games.js`：游戏页与二级分类
- `data.js`：比赛、视频、Bilibili 主页和游戏数据
- `assets/avatar.png`：网站头像

提交后等待 GitHub Pages 自动部署，再按 `Ctrl + F5` 强制刷新。
