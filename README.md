# My Archive — Work & Football V5

这一版重点重做足球档案交互。

## V5 新增

- 球员姓名：**暴力中锋**
- 足球页最前方新增年度 + 月度数据图表
- 年度 / 月度图表可切换「进球 / 助攻」
- 图表数据统一按**逐场比赛相加**计算
- 赛季面板的「进球 / 助攻」是可点击按钮，有选中和按压反馈
- 比赛记录改成「年份 → 月份 → 比赛」结构
- 每个月可折叠 / 展开
- 月度进球、助攻均按当月逐场比赛相加
- 一级比赛页只显示：日期、地点、进球、助攻
- 点击某一场进入 `match.html` 二级详情页
- 二级页显示：比赛名称、时间、地点、赛制、位置、跑动、备注、逐球记录、助攻记录、对应视频
- 每粒进球在二级页单独编号为 G01 / G02 / G03…，可以通过 URL 直接定位
- 视频支持按「日期 + 时间重合」自动匹配到比赛二级页

## 视频数据怎么写

在 `data.js` 最下面的 `videos` 数组里添加：

```js
{
  title: "8.18 石鼓八人完整比赛",
  date: "2026-08-18",
  time: "20:00-22:00",
  type: "完整比赛",
  url: "https://你的视频链接"
}
```

二级页面会先匹配同一天，再比较比赛时间与视频时间是否重合。

如果你希望强制把某个视频绑定到某一场，也可以添加：

```js
matchKey: "2026-08-18|石鼓八人"
```

`matchKey` 的格式是：`日期|比赛名称`。

## 当前数据口径

网站的图表、月份总计、比赛列表、赛季交互数字均按逐场记录相加。

原始文档里的年度汇总数字仍保留在 `seasonSummary` 中用于对照；例如原记录中 2022 助攻与 2025 进球存在年度汇总和逐场相加不一致的情况，网站不会静默修改源数据，而是在赛季说明中提示。
